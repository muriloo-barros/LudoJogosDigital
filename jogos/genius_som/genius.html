DAS CORES

Observe, memorize e repita a sequência!

Aviso ao Tutor: Este jogo foi criado principalmente para crianças surdas. Todo o jogo funciona 100% de forma visual, sem precisar de som. Cada rodada mostra uma sequência de cores e formas piscando, e a criança deve repetir a sequência na mesma ordem, tocando os botões. Também é possível jogar só com o teclado: pressione Tab uma vez para entrar no tabuleiro, use as setas (← → ↑ ↓) para navegar entre os botões, e Enter ou Espaço para escolher um.

A criança quer ouvir narração falada durante o jogo?

Se escolher "Não", as instruções vão aparecer em uma caixinha de texto, com as letras surgindo aos poucos, como se alguém estivesse falando — sem precisar de som.
